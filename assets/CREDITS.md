# Console icon references and credits

## Support artwork

The [Ko-fi support banner](support/isshelf-support-banner.png) and [coffee/controller decoration](support/isshelf-tip-decoration.png) were created with OpenAI's built-in image generation tool on 3 November 2026 from Iswebro's project direction. They are used only on the repository front page and are not bundled in the PS5 application. The controller is a generic stylized gaming controller, not an official product image or endorsement. The images are offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) to the extent rights are held; credit isShelf / Iswebro and note the AI-assisted generation.

isShelf includes 52 newly generated, transparent 3D-style system icons in [`3d-icons/`](3d-icons/). The Switch 2 card and detail view both show the revised generated icon. The icons are stylized illustrations, **not photographs or rotatable 3D models**, and small details may differ from the real hardware. The original Wikimedia Commons photographs are linked below, not bundled in the public repository. Grid view can also show text cards; Swipe and Shelf always use the console illustrations.

## Room scenery

The silent [Shelf TV demo](room/shelf-intro.mp4) is an original animation of the project's approved S bookshelf logo,
with Poppins lettering. It was generated by [tools/build-room-demo.py](../tools/build-room-demo.py), using Pillow and
FFmpeg; dimensions, codec targets and SHA-256 values are in [room/manifest.json](room/manifest.json).
It is labelled as a Shelf demo when used as a fallback, and contains no official console startup footage or sound.

The 52 [original console intro sets](room/intros/manifest.json) were composed with
[tools/build-console-intros.py](../tools/build-console-intros.py), using the existing, unchanged hardware illustrations,
the approved S logo, Poppins lettering and original animation/layout code. Each set contains a PNG poster,
silent MPEG-1 movie for the PS5, and MP4 rendition for the PC preview. Source-art and output hashes are retained
per console. These are original Shelf identity animations, not recordings or copies of manufacturer boot sequences.
Pillow and a privately verified portable FFmpeg build were used to render/encode them; neither tool is bundled.

The active [gaming lounge](backgrounds/gamer-lounge-v1.png) and [deep-counter Shelf room](backgrounds/gamer-lounge-deep-v1.png) were created with OpenAI's built-in image generation tool on 25 October 2026. Shelf renders its consoles into the room's actual furniture; it no longer pastes opaque shelf-panel photographs over another room. The original generated PNGs are used unchanged. Measured surface coordinates, dimensions, hashes and active image paths are in the [scene manifest](backgrounds/manifest.json), shared by the browser and C++ renderer.

A [standard-depth alternative](backgrounds/gamer-lounge-standard-v1.png) is retained as an artwork variant. Prompts: [base room](backgrounds/gamer-lounge-v1.prompt.txt), [standard counters](backgrounds/gamer-lounge-standard-v1.prompt.txt), [deeper counters](backgrounds/gamer-lounge-deep-v1.prompt.txt). The standard variant used the project's own [layout diagram](backgrounds/gamer-lounge-layout-guide.svg) as a composition guide and the base room as a style reference. The deeper variant edits that room. No outside room photograph was used.

The earlier [gallery study](backgrounds/gallery-room-v1.png) and [standalone shelf study](backgrounds/display-shelf-v1.png) remain in the source history with their original prompts. They are no longer the app's scenery. All generated scenery is offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) to the extent rights are held; credit isShelf / Iswebro (formerly Console Shelf) and note the AI-assisted generation.

## Hardware references

The PS2 illustration's bright blue base beneath the controller was changed to matte black with the built-in image generation tool on 25 October 2026. The PS2 lettering and controller button colours were retained. The [edit prompt](3d-icons/ps2-base-edit.prompt.txt) and [before/after hashes](3d-icons/ps2-base-edit.json) record that correction; its hardware reference and license remain as credited below.

The Mega Drive icon was revised on 25 October 2026 to depict the PAL Model 1 using Evan-Amos's reference above. It replaces the earlier Japanese-model illustration and uses the PAL hardware's neutral controls and three-button pad. The previous generated icon is kept only in the ignored local archive. The app icon variants were also generated for Console Shelf and are offered under CC BY 4.0 to the extent rights are held.

The Switch 2 icon is a newly generated dock-and-grip illustration based on [Nintendo's official Switch 2 press image](https://nintendoes-newsroom.prgloo.com/resources/nintendo-switch-2). The press photo is not bundled or displayed. Nintendo owns the hardware design and press image. The card is a visual reference only; no Switch 2 PS5 emulator has been verified.

The 33 other expansion icons were prompted from general hardware features and an existing Shelf icon as a style reference, without a specific downloaded photograph. See [the prompt brief](3d-icons/PROMPTS.md) for the list. Platform icons for arcade boards and computers are especially interpretive. No PS6 icon was created because an official PS6 console design could not be verified.

The first 18 reference URLs and local research file hashes are in [source-manifest.json](source-manifest.json); those local photographs are omitted from the public repository. Generated icon hashes and reference types are in [3d-icons/manifest.json](3d-icons/manifest.json).

The PS5 home tile uses the [isShelf vector icon master](branding/isshelf-home-icon.svg), rendered to a square PNG for the package. It reuses the prepared S mark on a dark background. The transparent vector mark is the default inside the app; the original Gaming, Classic mint and Jade artwork remains selectable. The vector master and exported tile follow the same CC BY 4.0 artwork terms.

The earlier [static launch composition](backgrounds/shelf-ps5-home-v1.png) was rendered by Shelf's native `launch-art` scene using its own app icon and the licensed Poppins fonts. It is retained as a background alternative.

The new [Glass and Light PS5 home-screen artwork](backgrounds/shelf-ps5-home-v2.png) was created on 26 October 2026. The glass-and-light plate was generated with OpenAI's built-in image tool at 1672 × 941, then composed at 3840 × 2160 with a [transparent vector redraw](branding/shelf-gaming-mark.svg) of isShelf's approved gaming logo. The logo contains SVG paths, rectangles and gradients, with no embedded bitmap or square icon background. [Prompt and composition notes](backgrounds/shelf-ps5-home-v2.prompt.txt) and the self-contained [composition SVG](backgrounds/shelf-ps5-home-v2.svg) are included. It contains no external photograph or personal library data. The composition, plate and vector redraw follow the project's existing CC BY 4.0 artwork terms to the extent rights are held; credit isShelf / Iswebro (formerly Console Shelf) and note the AI-assisted background generation. The matching PS5 DDS files and the verified, host-only Microsoft DirectXTex encoder are identified in `native/ps5/presentation-assets.json`; the encoder is not redistributed.
